2026.0.1

Die wichtigsten Merkmale

  • Version von TEKSI Abwasser für QGIS 3.40 LTR und installiert und Upgrade über den PostgreSQL Update Manager (PUM) und das TEKSI Module Management Tool (TMMT).

  • Weitere Informationen zur Installation von TEKSI Abwasser über TMMT finden Sie in der Installationsanleitung.

  • Das ‚Selektions-Erweiterungs-Tool‘ erlaubt es Nutzern, eine bestehende Selektion des Layers vw_tww_Haltung auf verknüpfte Objekte

  • New visualisation of channel damages

  • The ‚Refresh network topology‘ is only visible in Admin mode as the query can take quite long for big networks.

  • Verbesserung der Bezeichnung-Synchronisation für Abwasserbauwerke

  • Benutze Abwasserknotenbezeichnungen für die Haltungsbezeichnungen bei neuen Haltungen

  • Werkplan: Haltungen können jetzt mit E1, E2, …, A1, A2 beschriftet werden (Haltungspunkt-Beschriftungen)

  • Konfiguration im TWW-Projekt für Rohrprofil-Geometrien , inklusive einem im Projekt gespeicherten SQL um diese Rohrprofil-Geometrien zu visualisieren visualize profile-geometries

  • Kontrolle der Länge von Bezeichnungen werden dem Erfassen mit zwingenden Restriktionen (constraints) im Attributformular

  • Das OID Prefix kann in TMMT gesetzt werden ab Version 2026.0.1

  • erzeugt _CH Kopien der Übersetzungsfiles ( ‚*.qm‘ )

  • Import der VSA Organisationen aus dem Internet falls diese noch nicht vorhanden sind

Die folgenden Views wurden angepasst und müssen in bestehenden TWW 2025 Projekten geändert werden:

  • Verbesserte Konfiguration in vw_tww_catchment_area_totals (point-layer) vw_tww_Gesamteinzugsgebiet (Punkt-Layer)

  • Hinweis betreffend notwendiger Stammkarten in vw_tww_Einzugsgebiet, Tab FS_Stammkarte Sonderbauwerk

  • Info ob das Abwasserbauwerk eine Stammkarte hat, im Hauptlayer hinzugefügt

  • vw_tww_Haltung: Beschriftungen für rp_from_label und rp_to_label umbenannt und mit replace-Funktion, so dass die definierten Variablen für die Übersetzung verwendet werden

  • vw_tww_Abwasserbauwerk: Symbolisierung: Ersatz von not „tww_is_primary“ ` mit `(not „tww_is_primary“ or „tww_is_primary“ is NULL)

  • vw_tww_Abwasserbauwerk: Attributformular: AK_Hoehengenauigkeit auch mit der Option Zuletzt eingegebenen wert wiederverwenden (analog wie bei DE_Lagegenauigkeit)

  • vw_tww_Abwasserbauwerk: Attributformular: _input_label, _output_label ersetzt mit _reach_point_label

  • Neue Projektvariable tww_language: folgende Werte sind zulässig _en, _de` oder _fr

  • vw_tww_Haltung Beschriftungsdefinition: statt „material_abbr_en“ neu case when @tww_language = ‚_de‘ then „material_abbr_de“ when @tww_language = ‚_fr‘ then „material_abbr_fr“ else „material_abbr_en“ end

  • Neue Beziehung pipe_profile.obj_id to profile_geometry.fk_pipeprofile

  • profile_geometry (Rohrprofil_Geometrie) Attributformular konfiguriert

  • Rohrprofil Attributformular (Rohrprofil_Geometrie Subtabelle nur für die Profiltypen Spezialprofil, Maulprofil, offenes_Profil)

  • Neu ein SQL „visualize profile_geometry“ für den Aufruf aus SQL ausführen

  • Alle Bezeichnungsfelder: Neu mit erzwungener Restriktion length(„identifier“ )<=nn or „identifier“ is NULL (sonst verliert man alle Änderungen, wenn die Bezeichnung zu lang ist)

  • vw_Abwasserbauwerk : tww_is_primary, _channel_usage_current, _channel_function_hierarchic, _owner_organisation_type sind nicht editierbar. _channel_usage_current, _channel_function_hierarchic, owner_organisation_type konfiguriert als Wertbeziehung

  • vw_tww_Ueberlauf: _channel_usage_current, _channel_function_hierarchic sind nicht editierbar. _channel_usage_current, _channel_function_hierarchic konfiguriert als Wertbeziehung
