Hier sind Informationen zum geplanten 2027.X Release von TEKSI Abwasser

2027.0.0 Tech preview

Warnung

Dies ist eine technische Vorschau des TEKSI-Abwassermoduls für QGIS 4.4 LTR. Es handelt sich noch nicht um eine stabile Version; sie ist ausschließlich für Testzwecke und zur Einholung von Feedback gedacht. Bitte melden Sie auftretende Probleme an das TEKSI-Entwicklungsteam.

Die wichtigsten Merkmale

  • Erste Version von TEKSI Abwasser für QGIS 4.4 LTR und installiert und Upgrade über den PostgreSQL Update Manager (PUM) und das TEKSI Module Management Tool (TMMT).

  • Weitere Informationen zur Installation von TEKSI Abwasser über TMMT finden Sie in der Installationsanleitung.

  • Zusätzlich wurde das XTF-Fehlerprotokoll des ilivalidator eingebunden (nicht nur die –log-Variante), sodass Sie das aktualisierte QGIS-Plugin XTFlogChecker direkt nutzen können, um die Fehler zu visualisieren und einfach zu beheben.
