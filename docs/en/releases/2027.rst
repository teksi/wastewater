2027.0.0 Tech preview
=====================

.. warning::
   This is a tech preview of the TEKSI wastewater module for QGIS 4.4 LTR. 
   It is not yet a stable release and is intended for testing and feedback purposes only. 
   Please report any issues you encounter to the TEKSI development team.


Main features
----------------
- First Version of TEKSI wastewater module for QGIS 4.4 LTR and initialized and upgrade via the PostgreSQL Update Manager (PUM) and the TEKSI Module Management Tool (TMMT).

- Check the `installation guide <../installation-guide/index.html>`__ for more information on how to install TEKSI wastewater module (TWW) via TMMT.

- Added xtf error log of ilivalidator also (not only the --log version), so that you can directly use the updated QGIS XTFlogChecker plugin to visualize the errors and easily correct them.
