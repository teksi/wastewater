TWW Hooks Framework
===================


This section documents the TWW-specific hook framework used by TEKSI
wastewater workflows.

The framework separates parsed configuration, resolved runtime structures,
lookup capabilities and evaluators. It also documents the AGXX mapping
mechanism used for incremental update handling.
